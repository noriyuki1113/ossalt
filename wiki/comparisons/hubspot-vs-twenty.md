# HubSpot vs Twenty

## 比較の文脈

HubSpot の無料版コンタクト管理から始め、有料化が避けられなくなったスタートアップ・中小企業への代替提案。「CRM の基本機能（コンタクト・パイプライン管理）を OSS でセルフホストしたい」という需要に Twenty が応える。

## TL;DR

| 条件 | 推薦 |
|---|---|
| コンタクト・パイプライン管理だけが必要 | **Twenty** |
| HubSpot の有料化（Starter以上）を回避したい | **Twenty** |
| セルフホストでデータを自社管理したい | **Twenty** |
| マーケティングオートメーション（メール配信・シーケンス）が必要 | HubSpot |
| ランディングページ・フォーム作成が必要 | HubSpot |
| 高度なレポート・ダッシュボードが必要 | HubSpot |

## 各軸での詳細比較

### CRM コア機能の比較

Twenty はコンタクト（People）・会社（Companies）・商談（Opportunities）・タスク・メモ・アクティビティログを提供し、CRM の基本機能をカバーする。HubSpot のコンタクト管理と比べると、Twenty の方がカスタムオブジェクト（データモデルの自由な拡張）が使いやすく、開発者フレンドリー。シーケンス・メール自動化は HubSpot の方が充実。

### マーケティングオートメーションの差

HubSpot の最大の強みはマーケティングオートメーション。メールキャンペーン・ドリップシーケンス・フォーム・ランディングページ・ワークフローが統合されており、「マーケティングと営業を一元管理する」という CRM の本来の目的を実現している。Twenty にはこれらの機能がなく、「CRM の営業管理部分のみ」を代替できる。マーケティングオートメーションが必要な場合は、Twenty + Mautic（OSS メール配信）の組み合わせが必要。

### HubSpot の「フリーミアムトラップ」

HubSpot の無料版は コンタクト管理・パイプライン管理の基本機能を提供するが、実際のビジネスで必要になる機能（メール追跡・シーケンス・高度なレポート）は Starter 以上が必要。Starter は最低 $20/人/月（2 人で $40/月）から始まるが、Professional（$890/月〜）への移行を求められると年間コストが急増する。Twenty はセルフホスト版が無料で、CRM の基本機能をコスト 0 で使い続けられる。

### データ所有権と API の質

Twenty の GraphQL API はフル機能の API アクセスを提供し、自由なデータ取得・更新・外部システム統合が可能。HubSpot API も強力だが、HubSpot のクラウドに依存する点でデータ所有権に制約がある。Twenty のセルフホストは顧客データが完全に自社サーバーに留まる。

## 移行摩擦

### HubSpot → Twenty の主な作業

1. **コンタクトの CSV エクスポート**: HubSpot からコンタクト・会社・商談を CSV でエクスポート
2. **Twenty へのインポート**: CSV インポート機能でデータを移行（カスタムフィールドのマッピングが必要）
3. **HubSpot のメール・シーケンスの代替設計**: マーケティングオートメーション部分は別ツール（Mautic 等）を用意
4. **チームのトレーニング**: 新しい UI への適応（Twenty の UI は Notion ライクで学習コストは低め）

### Twenty に向かないケース

- **メールシーケンス・ドリップキャンペーンを多用している**: 移行先がない
- **HubSpot Forms を Webサイトに埋め込んでいる**: 別ソリューションへの置き換えが必要
- **HubSpot のレポートに依存している**: Twenty のレポート機能は基本的

## 日本語圏での選択傾向

日本では HubSpot が中小企業・スタートアップの CRM として広く普及しており、日本語サポートも充実している。Twenty はまだ認知度が低く、日本語 UI がないことが普及の障壁。「HubSpot が高くなった」を動機に OSS CRM を探すスタートアップが Twenty を試すケースが増えつつある。

## 結論

**コンタクト・パイプライン管理が主目的で、マーケティングオートメーションを使っていない**チームには Twenty は有力な HubSpot 代替。特に：

- HubSpot 無料版の制限に引っかかった
- データを自社サーバーで管理したい
- エンジニアがいて GraphQL API を活用できる

という条件が揃う場合は積極的に推薦できる。マーケティングオートメーションが業務の中心にある場合は、Twenty では代替できないことを明示して HubSpot の継続を推薦するか、Twenty + Mautic の組み合わせを検討する。
