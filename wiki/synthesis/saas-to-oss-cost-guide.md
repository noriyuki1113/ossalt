# SaaS → OSS 移行コスト試算ガイド

## このページの目的

「OSS に移行したらコストが下がる」は必ずしも正しくない。ライセンス費用はゼロになるが、インフラ費用・運用工数・習熟コストが新たに発生する。このガイドでは、主要 SaaS ツール別に移行前後のコスト構造を整理し、日本の中小チーム（10〜50名想定）が現実的に試算できる枠組みを提供する。

---

## 1. コスト構造の基本

### SaaS のコスト
```
月額費用 = ユーザー数 × 月額単価
  + オプション機能費用（AI・ストレージ・高度な権限）
  + サポート費用（エンタープライズプラン）
```

### OSS 移行後のコスト
```
総コスト = インフラ費用（VPS/クラウド）
  + 初期セットアップ工数（エンジニア時給 × 時間）
  + 継続運用工数（月あたり）
  + データ移行コスト（一回限り）
  + チーム習熟コスト（学習・オンボーディング）
  + アップグレード・メンテナンス工数（年あたり）
```

OSS 移行が「得」になるのは、SaaS 月額費用がインフラ + 運用コストを上回るケースのみ。

## 2. ツール別コスト試算（10名チーム想定）

### 2.1 Slack → Mattermost

**Slack（Proプラン）**
- $8.75/ユーザー/月 × 10名 = **$87.5/月（約13,000円）**

**Mattermost（セルフホスト）**
- VPS: 2vCPU/4GB RAM で月 $20〜30（Hetzner等）≒ **3,000〜4,500円/月**
- 初期セットアップ: 2〜4時間（エンジニア工数）
- 月次運用: 1〜2時間（アップデート・バックアップ確認）

**概算削減額**: 月 8,500〜10,000円 → 年 10〜12万円の削減

**条件**: エンジニアが月2時間の運用を担える場合。外部委託なら逆転する可能性あり。

---

### 2.2 Notion → AppFlowy / Outline

**Notion（Plus プラン）**
- $10/メンバー/月 × 10名 = **$100/月（約15,000円）**

**AppFlowy（セルフホスト）**
- VPS: 2vCPU/4GB RAM ≒ **3,000〜4,500円/月**
- 初期セットアップ: 3〜6時間
- データ移行: Notion → AppFlowy は自動化が限定的。コンテンツ量によっては 1〜2日の手作業
- 月次運用: 1〜2時間

**Outline（セルフホスト、Wiki 用途のみ）**
- VPS: 同等 + PostgreSQL/Redis ≒ **3,000〜5,000円/月**
- 初期セットアップ: 2〜4時間（Notion より容易）
- 移行: Notion の Markdown エクスポートから比較的スムーズ

**概算削減額**: 月 10,000〜12,000円 → 年 12〜14万円
**注意**: 移行初期コスト（エンジニア 1〜2日工数）を考慮すると、回収に 3〜6ヶ月かかる。

---

### 2.3 Jira → Plane

**Jira（Standardプラン）**
- $8.15/ユーザー/月 × 10名 = **$81.5/月（約12,000円）**

**Plane（セルフホスト）**
- VPS: 2vCPU/4GB RAM ≒ **3,000〜4,500円/月**
- 初期セットアップ: 3〜5時間
- Jira インポーター: 公式あり。カスタムワークフロー・権限は再設計が必要
- 月次運用: 1〜2時間

**概算削減額**: 月 7,500〜9,000円 → 年 9〜10万円
**注意**: Jira の複雑なワークフローを使い込んでいる場合、再設計コストが回収期間を大きく延ばす。

---

### 2.4 Airtable → Baserow / NocoDB

**Airtable（Teamプラン）**
- $20/エディター/月 × 5名（エディター） = **$100/月（約15,000円）**

**Baserow（セルフホスト）**
- VPS: 2vCPU/4GB RAM ≒ **3,000〜4,500円/月**
- 初期セットアップ: 1〜3時間（最も簡単な部類）
- 移行: CSV エクスポートから基本的なインポートが可能
- 月次運用: 0.5〜1時間

**概算削減額**: 月 10,500〜12,000円 → 年 12〜14万円
**評価**: Airtable → Baserow は移行容易度が高く、ROI が出やすい。

## 3. 意思決定フレームワーク

### ステップ 1: 現在の SaaS 月額を計算する
```
月額費用 = ユーザー数 × 単価 + オプション
```

### ステップ 2: 想定インフラコストを見積もる
- 10〜20名規模: 月 3,000〜8,000円（VPS 1〜2台）
- 50名規模: 月 8,000〜20,000円（冗長構成）

### ステップ 3: 移行・運用工数を見積もる
```
月次運用コスト = エンジニア時給 × 月あたり運用時間
（例: 5,000円/時 × 2時間 = 月10,000円）
```

### ステップ 4: 損益分岐点を計算する
```
回収期間 = 初期コスト ÷ (SaaS月額 - OSS月額コスト)
```

**移行を推奨するケース:**
- `SaaS月額 > OSS月額コスト × 3` 以上の差がある
- エンジニアが運用を内製化できる
- 5名以上のチームで移行後もユーザー数が増加する見込み

**移行を慎重に検討するケース:**
- チームに専任 DevOps がいない
- 移行後の習熟・オンボーディングコストが大きい（非エンジニア多数）
- SaaS の価格が低コストに抑えられている（スタートアップ割引等）

## 4. 見えにくいコスト

### 「ゼロ」に見えるが実際にかかるコスト

| コスト | 説明 | 目安 |
|---|---|---|
| アップグレード工数 | 年2〜4回のメジャーアップデート対応 | 年 4〜16時間 |
| バックアップ確認 | 定期バックアップの設定・確認 | 月 1〜2時間 |
| セキュリティパッチ | 依存ライブラリ更新・脆弱性対応 | 不定期 |
| チームサポート | メンバーの使い方質問への対応 | 月 1〜3時間 |
| ダウン対応 | 障害時の復旧・原因調査 | 年 2〜4時間（最低） |

### セルフホストのリスクコスト

SaaS は運用リスクをベンダーが負う。OSS セルフホストではこのリスクが自組織に移転する。
- データ消失リスク（バックアップ不備）
- ダウンタイムリスク（サービス停止）
- セキュリティリスク（脆弱性対応遅れ）

これらを「保険」として換算すると、SaaS のコストが正当化されるケースは少なくない。

---

## 5. 推奨アクション

### まず試すべき移行（リスク低・ROI 高）
1. **Airtable → Baserow**: 移行が容易、コスト削減効果が大きい
2. **Slack → Mattermost**: Slack ライク UI、移行ガイド充実

### 計画的に進める移行（リスク中）
1. **Jira → Plane**: インポーターあり、段階的移行推奨
2. **Notion（Wiki 用途）→ Outline**: ドキュメント限定なら比較的スムーズ

### 慎重に検討すべき移行（リスク高）
1. **Notion（全機能）→ AppFlowy**: 機能ギャップと移行コストが大きい
2. **Figma → Penpot**: .fig 変換精度と習熟コストに注意
