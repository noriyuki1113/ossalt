# NocoDB

## description_en

NocoDB turns any database (MySQL, PostgreSQL, SQLite, MariaDB, SQL Server) into a smart spreadsheet with a no-code interface. It is positioned as a self-hostable Airtable alternative, supporting grid, gallery, kanban, form, and calendar views. REST and GraphQL APIs are auto-generated.

## description_ja

NocoDB は既存のデータベース（MySQL/PostgreSQL/SQLite等）をスプレッドシートUIで操作できるノーコードツール。グリッド・ガレリー・カンバン・フォーム・カレンダービューをサポートし、REST/GraphQL APIを自動生成する。セルフホスト可能なAirtable代替として位置づけられる。
