# AFFiNE

## description_en

AFFiNE is an open-source knowledge base combining docs, whiteboards, and databases in one workspace. It markets itself as a "KnowledgeOS" and supports local-first storage, self-hosting, and real-time collaboration. Edgeless canvas mode bridges the gap between Notion-style docs and Miro-style whiteboards.
